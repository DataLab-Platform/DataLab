# Version 1.5 #

## DataLab Version 1.5.0 ##

### Requirements ###

* Runtime requirements are unchanged since version 1.4.2.

### New Features ###

* **Image contrast**: the contrast panel can now create an image from the histogram bounds without re-entering them in a processing dialog. The bounds apply to every selected real-valued image; source pixels stay unchanged and the bounds remain editable on each result (part of [Issue #370](https://github.com/DataLab-Platform/DataLab/issues/370)).
